# 2ndView — Watch YouTube Without Ads

> **YouTube videos play without any ads** — no pre-roll, no mid-roll, no interruptions. Just the video, in a clean full-screen overlay, directly on the YouTube page.

---

## What It Does

**2ndView** is a Chrome extension that opens any YouTube video in a separate clean overlay player — right on top of the YouTube page.

**The video plays without ads. No waiting. No interruptions. Ever.**

- No pre-roll ads before the video starts
- No mid-roll ads interrupting playback
- No recommendation sidebar, no comments, no autoplay distractions
- Starts from the exact same timestamp as the original video
- Works automatically — browse YouTube as normal, 2ndView handles the rest
- Close the overlay instantly with `Esc` or click outside — you're back where you were

---

## Features

### Ad-Free Playback

| Feature               | Description                              |
| --------------------- | ---------------------------------------- |
| **No pre-roll ads**   | Video starts immediately                 |
| **No mid-roll ads**   | Playback is never interrupted            |
| **No sidebar**        | No recommendations pulling you elsewhere |
| **No autoplay queue** | You control what plays next              |
| **No comments**       | Pure, distraction-free viewing           |

### Player Controls

| Feature              | Description                                                 |
| -------------------- | ----------------------------------------------------------- |
| **Auto-open**        | Overlay opens automatically when a video plays              |
| **Timestamp sync**   | Picks up from the same point as the original video          |
| **Resize slider**    | Drag to resize — 10% to 90% of screen width and Full Screen |
| **Persistent size**  | Remembers your preferred size                               |
| **Right-click menu** | Right-click any YouTube link → "Open in 2ndView"            |

### Settings (Extension Popup)

| Toggle                   | What it does                             |
| ------------------------ | ---------------------------------------- |
| **Enable 2ndView**       | Master on/off switch                     |
| **Open every video**     | Auto-open on every video you navigate to |
| **Keep open on refresh** | Restore the player after page refresh    |

### Keyboard Shortcuts

| Key           | Action          |
| ------------- | --------------- |
| `Alt + 2`     | Open 2ndView    |
| `Esc`         | Close overlay   |
| `Space` / `K` | Play / Pause    |
| `←` / `→`     | Seek ±5 seconds |
| `↑` / `↓`     | Volume ±10%     |
| `M`           | Mute / Unmute   |
